# Facebook Unfollow Helper (Chrome extension)

## Install
1. Extract `facebook_unfollow_helper.zip`.
2. In Chrome, open `chrome://extensions`.
3. Turn on **Developer mode**.
4. Click **Load unpacked** and select the extracted `facebook_unfollow_helper` folder.
5. Open Facebook and sign in normally.

## Use
1. Click the extension icon.
2. Click **Open Feed Preferences** or navigate to Facebook's Feed Preferences / following lists yourself.
3. Click **Scan this Facebook page**.
4. Review the page, then click **Start unfollowing visible items** and confirm.
5. Use **Stop** to halt the process.
6. Repeat on other Facebook lists if needed. You may need to scroll/load more entries and scan again.

## Limitations and safety
- This is a best-effort helper for Facebook's visible interface, not an official Facebook feature.
- Facebook frequently changes labels and layouts. Some controls may not be detected or may be interpreted differently.
- It does not guarantee a true one-click unfollow of every friend, Page, or group.
- It does not use Facebook APIs, collect passwords, or send data anywhere.
- Review the page and use at your own risk. Unfollowing is not the same as unfriending or leaving a group.
